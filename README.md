# SDOH Assessment Tool — AACCAA FY27 (hosting only)

This repository hosts the **blank intake form** for the Anne Arundel County
Community Action Agency's FY27 Social Determinants of Health program.

**Live form:** https://hatchjoshua137-jpg.github.io/aaccaa-sdoh-intake/

## No data lives here

This site is hosting only. The form runs entirely in the user's browser:

- No participant information is collected, transmitted to, or stored on this
  site or repository — there is no server, no analytics, and no external
  requests of any kind.
- All case data stays on the navigator's own device and is backed up only to
  the agency's Microsoft 365 / SharePoint environment.

The program's data workbook, documentation, and build sources live in the
agency's private repository.
